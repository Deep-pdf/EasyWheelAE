Optional Components

1. Browser Extension Installation
- Open Google Chrome (or your preferred Chromium-based browser).
- Navigate to the extensions page (chrome://extensions/).
- Enable "Developer mode" using the toggle switch.
- Click the "Load unpacked" button.
- Select the "Browser Extension" folder located inside this directory.

2. After Effects Extension Installation
- Navigate into the "EasyWheelAE" folder.
- Go into the "installer" folder.
- Run the "install.bat" batch file to automatically install the extension.
